Every record below is held in this repository. The page makes no request to any third party when it loads. If every upstream endpoint were withdrawn tomorrow, this index would still resolve and still show what existed, when it was captured, and where it used to live.

Metadata only. No dataset contents are mirrored here.

This index records what a dataset is, who publishes it, and how it can be reached. It does not contain the records inside any dataset. 79 datasets carry terms indicating person-level content — arrests, citations, calls for service, ownership, court, payroll. Those are indexed as existing and marked never-mirror. The flag is a stop condition, not a judgement that the publisher was wrong to publish.

Provenance

Upstream snapshots are kept in catalog/raw/ exactly as received. The full normalised record, including fields not shown above, is in catalog.json. Generation is reproducible from ingest.py.

One attribution error was made and corrected during the first build: 8,110 hosted services were pulled from an ArcGIS organisation assumed to be Johnson County. Verification against the portal API showed the organisation was the University of Wisconsin–Madison, and the records were student coursework. They were removed before publication. Recorded in PROVENANCE.md rather than quietly dropped, because a catalogue that hides its own corrections cannot be audited.
